# 本地演示步骤

1. 双击 start_demo.bat，选择离线演示，确认只输入成年人虚构案例。
2. 输入“最近工作很多，我想先聊聊。”，看到固定离线示例与研究记录。
3. 再输入一句虚构消息，确认多轮历史可见；点击清除当前会话，确认历史消失。
4. 打开 data/eval/dev.jsonl 与 reports/development，查看场景和逐轮运行结果；mock 指标明确未评测。
5. 本机配置 .env 后选择 DeepSeek API，确认费用和数据流向，再用少量虚构输入验证真实接口。2026-10-29 已通过一次固定虚构案例的评估→回复→检查真实调用；页面可以按上述步骤继续手动体验。

规则层的即时支持、未知、转述、跨轮保留等行为由 tests/test_policy.py 和 tests/test_workflow.py 验证，不把固定回复演示包装成模型识别能力。
