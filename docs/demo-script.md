# 本地使用与 API 验证步骤

1. 在本机配置 `.env`，然后双击 `start_demo.bat` 启动页面。启动脚本名称沿用旧版，对话统一使用 DeepSeek API。
2. 从首页选择“开始对话”，先确认只输入成年人虚构案例，再检查 DeepSeek 配置并确认数据发送与调用费用。配置未就绪时先修复本机配置；进入准备页不发送模型请求。
3. 进入聊天后输入一段明确的虚构消息，例如“这是成年人虚构案例：最近工作任务很多，我想先说说感受，不急着要建议。”发送后查看实际 API 回复与本轮状态；调用失败时核对页面的错误提示。
4. 如需验证多轮历史，再发送一句虚构消息；需要保留时主动导出。“清空本轮”会清除当前会话及探索记录。不要用真实用户健康材料做接口验证。
5. 从首页选择“做心理小测试”，选定功能和版本，逐题填写并观察进度；返回上一题确认草稿仍在，核对后提交，在独立结果页查看本机计分。问卷计分不发送 API 请求。
6. 从首页选择“从对话探索自己”，依次完成范围、API、主题、整理方式与最终单独同意。仅浏览设置不会启用观察；整理对话线索才会产生额外 API 用量。

单例接口检查可以运行 `python -m scripts.live_smoke`，它仅使用固定虚构案例。模型流程验证使用真实 API；规则、计分、状态和错误处理仍有本机自动回归，测试替身仅用于控制单元测试输入，不提供产品演示模式，也不视为模型识别能力证据。
