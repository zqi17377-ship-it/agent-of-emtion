# 本地使用与 API 验证步骤

1. 双击 `start_demo.bat` 启动页面。启动脚本名称沿用旧版，对话统一使用 DeepSeek API。
2. 从侧栏进入“API设置”，在遮罩框填写自己的DeepSeek API Key，核对模型名称并保存。网页新会话不会借用本机或部署者的 `.env`；保存不调用模型。地址固定为官方DeepSeek。
3. 如需检查连接，主动测试已保存配置。它只发送一次简短请求，不包含聊天历史，可能计费。随后返回原功能；配置只在当前网页会话的服务端内存中保留，不写文件或分享给其他使用者。
4. 从首页选择“开始对话”，先确认只输入成年人虚构案例，再确认连接及数据发送与调用费用。进入聊天后输入明确的虚构消息，例如“这是成年人虚构案例：最近工作任务很多，我想先说说感受，不急着要建议。”发送后查看实际API回复；正常回复不再重复显示动作成功提示，异常与紧急提示保留。
5. 需要保留对话时，从聊天顶栏“更多”选择“导出”；同一菜单中的“清空本轮”会清除当前会话及探索记录，菜单也提供“新对话”和“连接设置”。从首页选择“做心理小测试”，选功能和版本，逐题填写，核对后提交，在独立结果页查看本机图表与解读；问卷计分不发送API请求。
6. 从首页选择“从对话探索自己”，依次完成范围、API、主题、整理方式与最终单独同意；确认后直接进入聊天页，可从“探索详情”中的“设置对话探索”重新打开设置和关系标注，状态行“打开观察报告”可直接查看报告。更换或清除API配置会暂停观察并撤回相应启用同意，消息与已保存结果保留；需要继续时重新同意。清除配置后网页不能发送请求，也不借用其他人的密钥。

v0.6.2聊天页保留单层工具栏，空聊天为简短开场和三个紧凑预填按钮，点击只填入输入框，不自动发送。主题与整理方式在设置步骤直接展开并提供说明。点击“启用并开始对话”后，聊天观察状态行显示资料积累或整理状态；主题、资料门槛、进度与设置收在“探索详情”中。“打开观察报告”只进入报告页，不自动发请求。手动整理至少需要2条有效用户表达，达到门槛后在报告页主动点击整理。自动模式按已确认的既有门槛执行。资料进度不是性格评分。

v0.6新增测试可从“做心理小测试”进入：大五100、自我关怀12/26、正念15、依恋9/36和风险行为意向30题。自我关怀12题只看总体，26题另看六维；依恋9题先选对象，不同对象结果可分别回看。所有问卷在本机计分，不用API，仍然逐题作答、核对后提交。

v0.6.1共有17个可作答版本，小测试目录有12个主入口（10类问卷、MBTI风格、对话观察）。新增“ERQ-30（30题，英文原版）”和“AAQ-II（7题，英文原版）”，保留原英文指导语、题项和锚点，中文只用于界面和解释。无需配置API即可按研究范围进入这两份问卷。

检查本机计分时，可用固定的成年人虚构答案：AAQ-II七题都选4，核对后提交应为28分，原始范围7—49；高分表示更多心理不灵活或经验性回避。ERQ-30三十题都选4，十种策略应分别为12分，各自范围3—21，没有总分；原表中只有1、4、7附文字锚点，其他选项仅为数字。以上是可执行的验收步骤，不表示本次浏览器验收已完成。

展开“待接入的测试与来源”可查看BEQ16、FFMQ39的作者资料及待办原因；两者未内置题目、不能开始作答，不计入17个版本。BEQ作者目前只明确学术研究许可，不能据此确认覆盖当前个人研究或产品用途；FFMQ仍未取得明确嵌入授权。

命令行和独立脚本仍从本机 `.env` 读取配置。单例接口检查可以运行 `python -m scripts.live_smoke`，它仅使用固定虚构案例。模型流程验证使用真实API；规则、计分、状态和错误处理仍有本机自动回归，测试替身仅用于控制单元测试输入，不提供产品演示模式，也不视为模型识别能力证据。
