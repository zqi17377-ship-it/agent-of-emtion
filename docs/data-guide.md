# 研究资料说明

data/sources.json 登记本项目原创 AI 辅助草稿，未导入 PsyQA、ESConv、DAIC-WOZ 或医疗机构数据。40 张卡片是低风险支持表达草稿，不是临床诊疗指南的替代。

字段、许可与专业审核分别记录。当前卡片许可状态 permitted 仅表示这些新编文本可用于本项目研究，不表示内容已经通过专业审核。全部专业审核为 pending，reviewer 与 review_date 为 null。

案例标签是编写者提出的可接受回应动作集合，尚无专业金标准。80 个开发案例用于流程开发，40 个保留案例用于离线运行检查；同一编写方可以看到它们，独立性有限。保留集一旦用于提示词调参，应转入回归集并重新准备未使用材料。

scripts/seed_research_data.py 只用于初始化并拒绝覆盖已有数据。后续直接修改资料、记录版本和审核意见，不重复初始化。scripts/check_data.py 检查字段、来源、重复 ID 与跨集合家族；格式通过不代表医学内容正确或具有完整授权。

日常支持草稿只适用于中文成年人的虚构案例。匹配不到、适用性未知、许可未知或存在排除条件时，不返回相关卡片。eligible_pilot 还要求 approved、审核人和审核日期，且运行入口仍禁用。
