# 知心 v0.2 改版记录

日期：2026-10-29。

## 界面

温暖米白与深墨绿、统一间距与按钮层级；首页新增三类虚构场景入口。重要确认与模式选择位于正文，解决窄屏侧栏折叠后找不到启用方式的问题。聊天区使用区分明确的气泡和易读动作状态，原始 JSON 默认隐藏在可选研究记录中。

## 功能

- 新建、切换和移除浏览器内存中的对话，最多 10 个；切换模式会保留已有对话。
- 清空当前对话时，同时清除其判断、证据、结果和反馈。
- 主动导出当前对话的可见文本；不包含内部状态或 API 配置。
- 单条回复反馈仅留在当前会话，不写入训练资料、不自动上传、不重复请求模型。
- .env 每次新鲜读取，不再用 setdefault 把旧文件内容永久留在进程环境中；配置状态不返回凭据。
- 用户明确希望先被倾听时，优先倾听而非询问可选字段；已有即时支持、待澄清安全线索和专业评估需求仍优先。

## 验证

全套 93 项测试通过，覆盖配置热更新、会话隔离、导出与反馈、倾听优先级和页面交互。实际浏览器已验证场景填入、确认门槛、反馈、模式切换保留历史，以及两轮固定虚构场景的真实 DeepSeek 回复；回复均显示“先听你说”，第二轮回应了“项目延期、努力未被看见”的补充信息。

桌面与窄屏均已实际检查。已修正固定输入栏重复预留底部空间导致首页自动滚动遮住标题的问题；最终浏览器视口已恢复为原尺寸，回到未预勾选确认项的空白会话。
