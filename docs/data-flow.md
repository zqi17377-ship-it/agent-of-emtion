# 数据流

离线模式：本机浏览器 → Streamlit 会话内存 → 固定示例模型 → 页面。不开启外部模型请求。

API 模式：本机浏览器 → 本机程序 → DeepSeek 官方 API → 本机程序完成校验 → 页面。发送必要对话上下文、研究提示词和选中的知识卡；不发送环境变量或密钥作为消息内容。密钥仅在认证头中使用。

当前无数据库、跨会话共享对话缓存或自动训练收集。清除按钮删除本机会话中的消息、判断和证据；供应商端保存、删除和训练使用须另行核查。

评测脚本会把虚构案例的逐轮结果写到明确指定的 reports 目录，禁止传入真实用户数据。日志仅记录事件类型和允许字段名，不记录敏感字段的值。用户主动启用 API 会产生调用用量；超时不表示供应商已取消处理。
