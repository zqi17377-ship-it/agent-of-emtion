# v0.5.1 统一使用 DeepSeek API

根据用户明确要求，产品移除离线演示和模式选择，对话与模型分析统一使用已配置的 DeepSeek API。既有研究范围、数据发送与费用确认保留。

## 使用流程

聊天准备缩为两步：先确认研究使用范围，再检查 DeepSeek 连接配置并确认数据发送与调用费用，完成后进入聊天。准备过程本身不发送聊天请求。配置缺失时提示修复；模型调用失败会显示相应状态，不再用离线演示回复代替模型运行。

首页三个入口及问卷、探索功能的分步页面继续保留。问卷和原创偏好问答仍在本机计分，计分本身不需要模型调用。对话观察默认关闭，另经五步设置和最终单独确认后才启用。

命令行默认连接 DeepSeek，不再提供 `--mock` 演示入口。当前使用说明与验证步骤同步更新，历史发布记录保留其对应版本的实际状态。

## 验证方式

端到端和模型接口验证使用少量固定的成年人虚构案例，实际调用 DeepSeek API 并记录请求与工作流程状态。合成案例评测默认最多3个案例、12次请求，可用 `--limit` 和 `--max-requests` 进一步限制。连通验证不等于心理诊断、人格判断或临床效用验证。

计分、页面路由、授权状态与异常处理继续运行本机自动回归；可控的单元测试替身仅用于软件逻辑验证，不构成产品模式，也不计入实际 API 效果证据。

2026-10-30 最终完整回归：`python -m pytest -q`，322 passed in 44.90s；数据检查返回 `valid: true`。新增回归包括默认API、无模式选择、缺配置禁发、旧演示历史禁发，以及旧单聊天迁移时不能被重标为API。关键回归已观察先失败后通过。

实际浏览器走通两步准备，并发送一份固定成年人虚构工作压力案例。DeepSeek 返回成功，页面研究记录显示 `status=ok`、`action=listen`、`error_code=null`，模型 `deepseek-flash`，3次请求，5,042毫秒，已报告输入/输出3,708/201 tokens。对话观察保持关闭，没有额外分析请求。本次仅验证接口、授权与显示链路，不推定心理判断准确性或实际账单。

旧版演示历史保持可查看，继续使用时另开API对话；不把演示消息直接重标后发给模型。新的对话和移除最后一个对话后的空白对话均默认API。

页面与报告不显示 API 密钥，验证不使用真实健康材料，不将本地运行报告、会话数据或凭据加入源码发布。既有非商业研究、来源许可与专业审核边界见[心理探索工具说明](psychological-tools.md)。
