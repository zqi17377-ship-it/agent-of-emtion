# 对话探索引导实施计划

规格：[design](../specs/2026-10-30-exploration-guidance-design.md)。用户“继续”延续上一项界面改进，直接在现有应用实施。

1. 独立只读进度模块：`ObservationProgress` 与 `observation_progress(state,messages,*,authorized,live,paused)`，复用候选计数与调度原因。先测试首次20条且1000字、手动2条、后续10条、暂停/额度及重复过滤，再实现。不改变 scheduler。
2. 界面主题与模式改为带框的显式选择，短说明随选项展示。更新既有向导测试并新增清空阻止、往返与跨功能草稿恢复检查；先观察行为回归失败再修改实现。
3. 聊天观察卡片接入资料进度与直接报告导航，报告导航保留模式且不自动请求。确认页说明接下来进入聊天。根页面回归覆盖输入框、报告入口与状态隔离。
4. 检查相关回归、完整 pytest 和 check_data；浏览器操作完整流程、窄屏检查并保存截图。独立审查变更，更新说明，通过仅源码清单同步 GitHub。

审查重点：widget 隐藏后清理不会丢草稿；不同对话不串选择；选择自动但未确认不启用；进度仅反映资料量；API 缺失/撤回后不能显示可整理；旧报告可查看但不暗示已刷新。
