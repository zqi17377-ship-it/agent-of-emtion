# 每位使用者的API设置

用户明确要求UI提供修改API入口，便于推荐给别人，让他们填写自己的API。沿用现有DeepSeek官方连接，不增加任意第三方端点，不改变研究确认或量表内容。

侧栏常驻“API设置”入口；聊天准备连接步骤也能进入。独立设置页提供遮罩API Key与可编辑模型名称，固定显示官方地址；保存、主动测试连接、清除本次配置及返回入口明确。保存不请求模型；测试只使用已保存配置，一次简短合成连接测试，不发送历史聊天，最多1请求/15秒，使用者事先看到调用费用说明。

网页配置只在当前Streamlit会话的服务端内存保存，与不同浏览器会话隔离。不写.env、进程环境、日志、会话导出、缓存或源码；输入保存后清空密码控件，不把完整或部分密钥回显。每个新网页会话从无密钥开始，不自动借用部署者.env或环境变量。CLI与独立脚本仍使用既有本机配置机制。

后端提供不可变、repr隐藏密钥的显式配置对象，以及安全就绪状态。模型工厂支持明确传入配置；网页所有聊天、旧MBTI分析、手动和自动观察均传入当前会话的配置快照，不在后台线程读取Streamlit会话或重新读取全局密钥。配置清除/更换时暂停本会话全部观察，增加revision使排队任务失效，并清除相应启用同意；已保存聊天/问卷/性格记录与已花费预算保留。已经发出的远程请求无法撤销。

设置页返回恢复原来功能路径，不清空草稿。密钥留空可保留本次已保存密钥用于只改模型，首次空密钥拒绝；清除后网页无法发送且无全局fallback。错误提示只使用预定义错误码，不能显示异常正文、请求头、供应商正文或凭据。对新页面解释服务端会处理密钥，不声称仅在客户端或加密永久保存。

验证包含两个独立AppTest会话、save/clear/换模型、无.env fallback、导出与repr不泄漏、线程配置快照、撤回后的旧任务不再发请求、路由返回、保存不发请求、连接测试单次预算。真实API仅用已授权的本机配置在程序内部生成显式配置做有限合成验证，不把密钥读入聊天或截图。源码发布排除凭据/运行报告。
