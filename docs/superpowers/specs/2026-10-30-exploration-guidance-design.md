# 对话探索的选择与聊天引导

延续用户对首次使用顺序清晰、选项直接展示以及设置后立即聊天的要求，继续改善现有五步流程。沿用 Streamlit 与现有配色；不改变分析提示词、同意范围、请求门槛和费用预算。

主题步骤使用三个可分别勾选的带框选项，说明 MBTI 风格、大五线索和依恋倾向分别探索什么。至少选择一项才能继续。整理方式以两个带框单选项展示，说明手动与自动的区别。返回、跨页面重新进入均保留当前对话的草稿；未最终确认前观察仍关闭。

确认页汇总选择并说明启用后进入当前聊天。聊天页的观察卡片展示资料积累进度和下一步说明，提供直接打开报告与现有设置的入口。资料进度按已有候选消息计数及调度原因展示，不解释为测量得分；点击报告只导航，不直接调用模型。模式关闭时保留简洁设置入口。

实现选择：继续使用原生 checkbox/radio 并局部加框，可保留键盘操作、标签和状态。自制 HTML 交互卡片需要额外组件且易破坏状态与可访问性，因此不采用。进度展示只读复用现有调度器，不建立第二套触发逻辑。

验收：主题清空时禁止下一步；往返保留选择；确认后仍直达可用聊天；当前会话进度能区分手动、首次自动、后续新增、等待、暂停和额度状态；导航不发消息。实际浏览器核对桌面与窄屏，软件回归与数据检查通过。纯 UI/state 修改不重复消耗模型请求，模型路径沿用已验证的真实 DeepSeek 链路。
