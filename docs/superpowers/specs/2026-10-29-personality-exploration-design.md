# 心理探索 · 对话性格与六份问卷

用户最初要求从对话分析类似 MBTI 的性格，后续明确加入依恋倾向和更多测试。最终范围为顶栏“心理探索”中的七类工具，采用独立页面和会话内状态，不将推测类型或问卷得分用于临床判断或改变安全规则。

## 工具范围和边界

| 工具 | 实际内容 | 结果 |
| --- | --- | --- |
| MBTI 风格对话性格 | 用户文字分析、八题原创非标准化偏好自述和用户自我确认 | EI 社交能量、SN 信息关注、TF 决策偏好、JP 安排方式；证据、反例和覆盖状态分别显示 |
| 依恋倾向探索 | 项目原创 12 题，各维 6 题 | 关系焦虑、亲近回避各自 1—5 均分；关系限定的本次应答参考 |
| Mini-IPIP | 公共领域英文题项的项目研究自译 20 题，各维 4 题 | 五维各自 1—5 均分，包括负性情绪倾向 |
| TIPI | 英文题项的项目研究自译 10 题，各维 2 题 | 五维各自 1—7 均分，包括情绪稳定性 |
| RSES | 公共领域英文题项的项目研究自译 10 题 | 自尊原始总分 0—30 |
| 应对信心探索 | 项目原创 6 题 | 当前自报应对信心均分 1—5 |
| SWLS | 英文题项的项目研究自译 5 题 | 生活满意度原始总分 5—35，仅限非商业研究 |

六份问卷全部本机计分，完整作答后才计算，不补值、不合并不同人格维度，不输出概率或常模百分位。Mini-IPIP 负性情绪倾向高分与 TIPI 情绪稳定性高分的含义不同，必须分别说明。反向题按量程端点反映；来源、许可、翻译和计分说明可在页面展开查看，并随问卷报告导出。

依恋和应对题目均为原创、未经信效度验证的探索练习，不是 ECR-R/ECR-RS 或 GSE 的题项、译本或验证版本。依恋先选定一段关系，切换关系后不混用答案；任一维均分在 2.5—3.5（含边界）时暂不归类，其余组合仅为明确标注的中点启发式，边界未经验证，不视为稳定类型。每份问卷保留本对话最近一次结果及其关系标签。

Mini-IPIP、TIPI、RSES、SWLS 中文题项为项目研究自译，未完成中文信效度验证，不冒称已发表或作者收录的验证中文版。IPIP、RSES 的公共领域说明和 TIPI 作者许可与当前项目的非商业研究范围分别记录；SWLS 明确仅限非商业研究，不推定商业授权。完整来源与许可见 [psychological-tools.md](../../psychological-tools.md)。

## 对话分析方法

分析只读取当前对话中用户发送的文字，逐字核验引用属于对应用户消息，不引用助手文字。模型不能提供人格准确率、医学概率或数值置信度。支持某个方向至少需要两段不同用户消息，这是保守的工程门槛，不是验证过的信度标准；未知和相反线索保留。自报四字母标签及标签片段不能成为证据。四字母参考由程序从四维结果生成，用户自行确认的偏好独立显示。

提示词仅寻找日常跨情境偏好，禁止从当前痛苦、症状、疾病、职业或身份刻板印象推断人格。程序的字面校验不能保证模型正确理解习惯或发现所有反例，因此结果仍需用户核对，不声称人格预测准确。

## 用户流程和状态

点击顶栏“心理探索”后选择工具。研究范围确认后可填写本地问卷。对话分析还需 DeepSeek 模式及配置就绪、API 数据流向与费用确认、至少两段用户消息，以及单独同意分析当前对话，主动点击后才额外调用模型。每次分析最多两次请求，共享 40 秒截止时间；没有点击不产生分析请求。问卷与自述答案不自动发给模型。

`ExplorationState` 管理每个 `Conversation` 的观察、分析错误、自述、确认、问卷答案、结果及关系标签。新对话隔离；用户文字更新后标记旧观察；失败分析保留先前观察并提示。当前需优先即时支持时暂停探索。未发送聊天草稿在进入探索、换工具、计算和返回聊天时保留。

清空或移除对话同时清除探索状态及相应控件；探索页也可单独清除记录，不清除聊天。数据只在当前浏览器会话对应的服务端内存中保留。性格和问卷报告主动、单独下载，聊天导出继续只包含聊天文本；报告不包含 API 配置或内部指纹。

## 依据与验收

[Myers & Briggs Foundation 的 best-fit 说明](https://www.myersbriggs.org/unique-features-of-myers-briggs/best-fit-type/)强调本人理解与核对最贴近自己的类型。[语言与人格的 PLOS ONE 原研究](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0073791)不能证明几句咨询对话足以准确判定 MBTI。本项目既不是官方施测，也没有完成人格预测准确性研究。

软件验收覆盖来源与限制可见、正反向计分和缺题拒绝、原话及助手隔离、未知和矛盾、调用同意与预算、状态隔离清除、单独导出、实际虚构案例 API 链路，以及浏览器目录、计分和草稿保留。验证结果记录在 [v03-verification.md](../../v03-verification.md)。临床效用、中文信效度、独立人格准确性和真实用户使用均不属于本轮完成声明。
