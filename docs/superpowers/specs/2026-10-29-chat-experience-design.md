# 知心 v0.2 聊天体验改版

用户要求改善难看的界面并继续完善功能，随后要求继续执行。本轮保留现有 Python/Streamlit 与 DeepSeek 管道，避免引入第二套前端和公开部署。

## 默认设计

采用温暖米白、深墨绿和少量鼠尾草绿；统一字号、间距、圆角与按钮层级。主区域为品牌栏、欢迎与场景入口、清晰的对话区和底部输入。窄屏的重要确认与模式选择在正文可见，不藏在折叠侧栏。

侧栏只承担当前浏览器中的会话列表与新建；正文提供当前对话标题、模式/配置状态、清空与主动导出。会话和反馈仅保存在当前浏览器会话内存；不自动写聊天文件，不收集训练数据。

## 功能

1. 新建、切换、清空和移除会话；最多 10 个，达到上限给出明确提示，不自动删除旧会话。
2. 三个虚构场景入口，只填充输入框，不自动发起 API 请求。
3. 单条回复有“有帮助/需改进”反馈；反馈仅在内存中，不因点击而重复调用模型。
4. 主动下载当前对话 Markdown，包含用户看到的文本，不导出密钥、内部证据、模型状态或诊断标签。
5. 安全配置状态和文件配置热更新；页面不显示密钥。明确保留模型数据流和虚构案例确认。
6. 没有安全/专业评估需求时，优先尊重“先听我说”，不因缺少持续时间等可选信息而机械追问；未知仍保持未知。
7. 正常生成、备用回复和当前支持指引分别显示易读状态；内部 JSON 放入可选研究记录。

## 验证

单元测试覆盖会话隔离、反馈与导出、配置热更新、倾听与安全优先级；AppTest 覆盖入口确认、场景填充、聊天、新建切换和清空。浏览器检查实际窄屏布局并保存完成截图。真实 API 只在有必要时使用固定虚构案例进行少量验证。

首版既有医学边界和真实用户试用限制继续适用，改版不构成新的临床验收。
