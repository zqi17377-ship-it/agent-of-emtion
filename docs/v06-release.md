# v0.6 心理小测试扩充

根据此前检索清单接入7个新版本，问卷由8个增至15个。入口仍为首页“做心理小测试”，同类工具先选版本，再进入说明、逐题填写、核对与独立结果页。

| 新增版本 | 反馈 |
| --- | --- |
| IPIP100 大五 | 五维各20题，1—5均分雷达；保留情绪稳定性及智性/想象力原方向 |
| SCS26 自我关怀 | 六维原始均分量程图，另列六维等权总体；负向三维反向计分并明示方向 |
| SCS-SF12 自我关怀 | 官方重排短版，只反馈总体，不输出六维画像 |
| MAAS15 成人特质 | 单维1—6均分；高分表示较多正念注意觉察，原锚点方向不再反转 |
| ECR-R36 | 一般亲密伴侣关系的焦虑/回避各18题均分，不给固定依恋类型 |
| ECR-RS9 | 选择母亲、父亲、伴侣或最亲近朋友中的一个对象；焦虑3题、回避6题，7点量程 |
| DOSPERT30 RT | 五个风险领域各6题，分别加总6—42；不合成总分，不鼓励尝试题中行为 |

均提供原始得分、图表、对应构念的本机解读、反思提示和主动导出。问卷答案不发送给模型，不产生额外API请求。不同版本分开记录；ECR-RS按版本与对象分别保存草稿、答案、结果和导出上下文，可以直接查看某段关系的上次结果。原有原创依恋12题的单份最近结果机制继续保留。

来源与许可已在介绍页、导出和[工具说明](psychological-tools.md)登记。中文均为本项目研究自译，未经中文心理测量验证。IPIP、MAAS为公共领域；SCS作者允许使用与翻译但新译本验证尚待完成；ECR按作者非商业研究/修改许可及RS页面所链FAQ的研究范围使用；DOSPERT依据出版社CC BY3.0署名并注明翻译改动。其余候选继续停用，没有注册、付费或复制受限题库。
