# v0.6.1 英文原版情绪调节与心理不灵活问卷

用户同意先使用英文原版后，新增ERQ-30与AAQ-II两个可作答版本，问卷由15个增至17个。首页“做心理小测试”共有12个主入口：10类问卷、MBTI风格和对话观察。BEQ16、FFMQ39仅显示待接入资料与原因，不内置题目、不可作答，不计入17个版本。

| 新增版本 | 题项、计分及结果 |
| --- | --- |
| ERQ-30，`erq30_en` | 30道英文原题，十种策略各3题，分别加总3—21；无反向题、无整体总分。高分表示更多自报使用相应策略，不表示策略总是有益或适合当前处境 |
| AAQ-II，`aaqii7` | 最终7道英文原题，全部正向加总7—49；高分表示更多心理不灵活或经验性回避，不表示心理灵活性更高 |

两项保留原英文指导语、题项和作答锚点，中文用于界面及结果解释。ERQ-30仅在1、4、7显示原文字锚点，其他档位保持数字；AAQ-II保留原七级频率锚点。均复用逐题填写、默认未答、返回修改、草稿、核对后提交、原始量程图和主动导出；得分及解读在本机生成，不向模型发送答案。

版本身份明确登记为`erq30:30:en-original:key-v1`与`aaq_ii:7:en-original:key-v1`，原有中文版本ID保持不变。ERQ-30十维独立展示，AAQ-II只展示心理不灵活/经验性回避单维；不套用原手册的美国样本分类、临床阈值或人群百分位，不宣称本应用已完成独立或临床验证，也不冒称已验证中文版。

## 来源与许可

- ERQ-30依据[Preece与Gross作者上传的问卷及计分手册](https://www.researchgate.net/publication/398122614_The_Emotion_Regulation_Questionnaire-30_ERQ-30_Copy_of_Questionnaire_and_Scoring_Instructions)，机构入口见[Stanford资源页](https://spl.stanford.edu/resources)。手册允许原表免费用于研究及临床的纸笔或在线施测；翻译、改编或修改内容须另获作者许可。本次仅在既有本地非商业研究范围使用英文原表，未制作中文题项译文。
- AAQ-II依据[作者页面提供的最终7题表格和计分](https://ruthbaer.com/academics/AAQ-II.pdf)及[ACBS所载作者Frank Bond许可](https://contextualscience.org/acceptance_action_questionnaire_aaq_aaqii)。研究及与来访者使用无需另行取得作者许可；营利用途需申请。本项目仅按本地非商业个人研究范围使用。
- BEQ16的[作者资源页](https://spl.stanford.edu/resources)目前只明确学术研究许可，未确认覆盖当前个人研究或产品用途；FFMQ39虽有[作者表格及计分](https://ruthbaer.com/academics/FFMQ.pdf)，仍未取得明确嵌入授权。两者保留资料链接，不将可下载推定为可内置。

## 验证与边界

- 完整软件回归：`python -m pytest -q`，533 passed in50.44s；`python -m scripts.check_data`，`valid=true`。
- 覆盖英文语言身份、旧版本ID兼容、独立计分键、原始量程、缺题拒绝、逐题入口、保存与导出入口，以及BEQ/FFMQ无题项、无作答按钮。独立只读集成审查未发现可操作问题。
