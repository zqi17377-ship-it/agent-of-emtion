# v0.5.3 每位使用者的API设置与对话入口

网页新增独立“API设置”页面。每位使用者填写自己的DeepSeek API Key和模型，不继承本机或部署者的 `.env`、环境变量，也不借用其他访问者的凭据。命令行与独立脚本继续使用原有本机 `.env` 配置。

## 使用步骤

从侧栏“API设置”或聊天准备的连接步骤进入设置页，在遮罩框填写密钥，核对模型并保存。默认模型为 `deepseek-flash`，可以按自己账号支持的模型修改。当前只接受官方DeepSeek地址，不提供任意第三方URL设置，接口说明见 [DeepSeek官方文档](https://api-docs.deepseek.com/)。

保存不会发送请求。主动测试连接时，只用已保存配置发送一次简短请求，不包含聊天历史；页面会事先说明可能产生API费用。返回后继续原功能，草稿保留。清除本次配置后网页不能发送模型请求，也不会自动使用部署者的凭据。

已有配置时，密钥留空可保留已保存密钥，只修改模型；首次保存仍需填写密钥。保存后的页面不回显密钥。每个新网页会话从未配置开始，刷新或关闭后配置可能丢失。

## 会话与观察

“从对话探索自己”的五步设置在最终确认后直接进入当前聊天页，显示已启用的整理方式并提供输入框。从聊天页“设置对话探索”仍可修改设置、管理关系、标注消息和查看报告。页面跳转不主动发送消息；自动整理仍按已确认的模式与既有消息门槛执行。

密钥由当前网页会话对应的服务端处理并仅保存在内存中，不写入文件、进程环境、日志或导出，不向其他访问者共享。这不是仅在客户端保存或加密永久存储。

更换或清除API配置会暂停该网页会话中全部对话的观察，并撤回相应启用同意，使旧的排队任务失效。已有消息、已保存问卷和性格结果，以及已花费的请求预算保留。需要继续观察时重新设置并同意启用；已发送的远程请求无法撤销。

聊天、MBTI对话分析、手动和自动观察使用当前会话的明确配置。配置为空时停止发送，不回退到其他人的密钥。设置页的错误提示不显示凭据、请求头或供应商返回正文。

本次范围是本地研究原型的配置与会话隔离，没有进行公开部署，也不改变非商业研究、专业审核和心理测量限制。
