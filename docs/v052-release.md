# v0.5.2 对话命名与测试结果展示

本次增加对话重命名、小测试直接展开选项，以及图表、逐维文字解读和反思提示。沿用统一 DeepSeek API 的对话连接方式与分步使用流程。

## 对话名称

在侧栏展开“会话管理”，选择“重命名当前对话”，填写1—40个字符的名称后点击“保存名称”。“取消命名”不更改原名称。保存后自定义名称不会被后续消息自动生成的标题覆盖；其他对话各自保留名称。“清空本轮”会把当前名称重置为“新的对话”，并恢复自动标题规则。

名称与消息一样属于当前浏览器会话对应的服务端内存，刷新或关闭页面后可能丢失。本次不增加自动持久化或网络发送。

## 逐题作答

心理小测试每页仍只显示当前一题，所有单选项直接展开，初次作答没有预选答案，不必再展开下拉菜单。选择后才能进入下一题；返回时保留已选答案，进度继续显示已答和剩余题数。全部完成后先核对，确认提交才保存计分结果。

八题原创偏好问答继续提供“不确定 / 看情况”选项，不强迫选择某一端。

## 结果图表与解读

大五TIPI10、Mini-IPIP20和IPIP50使用五维雷达图，展示本次题均分在各轴原始量程中的位置。轴的名称和方向依各工具保留：Mini-IPIP第四维的负性情绪倾向与其他版本的情绪稳定性方向相反，不为统一形状而反转分数。IPIP50的想象、抽象概念相关维度也不解释为智商。

其他单维或双维测试使用原始量程横图；圆点表示当前得分的位置。图形不是人群百分位或概率，雷达面积不表示人格总分，不把不同工具的图形大小直接当作变化幅度。

结果按每个维度给出本次作答解读及具体反思问题。较低、中间、较高仅是辅助描述，未经常模验证，不构成心理诊断。大部分工具按本量程三段描述；依恋原创练习的文字与参考分类共用既有2.5—3.5含边界中区规则，明确其为未经验证的项目启发式。生活满意度、自尊和应对信心分别描述其对应主题，不推导稳定人格类型；依恋只描述本次选定关系。

八题MBTI风格问答新增“本次偏好解读”：两题选择一致时说明明确选到的日常习惯；两题不同方向时保留两种线索；未答或不确定时保留未知，不据此确定稳定人格类型。

上述图表、计分、解读与反思提示在本机生成，不新增API请求，不自动把答案或解读发给模型。导出的问卷与偏好记录包含页面相同的文字解读；图形本身不嵌入Markdown导出。

图表使用原生SVG，经Streamlit图片组件显示，可展开查看；图表先展示，原始数值保留在“查看原始分数”详情。SVG提供标题与替代描述，解读也保留同样的维度与原始范围。
