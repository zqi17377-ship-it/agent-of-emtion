# 真实用户试用条件 — 尚未启用

- [ ] 明确专业负责人，审核全部安全策略、备用文案和重点知识卡。
- [ ] 明确成年人目标人群、地区、招募方式和适用的伦理/合规程序。
- [ ] 用真实模型完成独立人工评审和关键场景验证，修复严重已知问题。
- [ ] 落实服务商处理条款、数据留存、删除、同意与跨境问题。
- [ ] 建立实际可执行的现实求助流程、工作时段、责任人和异常事件处理。
- [ ] 完成多人部署所需的身份、隔离、访问控制、加密、限流和安全测试。
- [ ] 设置暂停条件：严重误导、隐私事件、求助流程不能执行等。
