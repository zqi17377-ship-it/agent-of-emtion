# v0.5.4 对话探索的选择与资料进度

继续改善初次使用流程。主题步骤将 MBTI 风格、大五人格线索和关系依恋倾向直接展示为三个带边框、带简短说明的勾选选项；至少选一个才能继续。整理方式用两个展开的单选框说明手动与自动的区别，前后步骤按钮并排。主题与模式草稿按对话保留，离开功能或切换对话后可以继续。

最后“启用并开始对话”进入当前聊天。聊天页观察卡片展示资料积累和下一步提示，支持直接打开观察报告及原有设置。打开报告只导航；是否开始整理仍遵循既有授权和调度规则。

资料进度复用既有候选过滤和调度原因：手动至少2条有效表达；首次自动20条且至少1000非空白字符；之后每新增10条复查，最多3次自动整理。首轮进度同时考虑条数与字符数，后续按新增条数显示；等待授权、支持暂停、后台整理、已尝试资料、额度与自动次数上限有各自提示。进度不表示性格得分、人格判断准确度或测量有效性。短回复、重复和助手消息不用于累计。

未修改模型提示词、题库内容、同意范围或请求预算。观察仍默认关闭，保留研究范围与心理测量限制。
