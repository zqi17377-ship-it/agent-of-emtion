# 回应策略研究草稿

五类主动作：listen 倾听、clarify 澄清、support 日常支持、refer 专业评估建议、urgent_support 即时安全支持。主动作不等于诊断或未来自伤概率。

规则优先处理有明确证据的当前即时支持需求。未解决线索跨轮保留，转移话题或否认本身不会清空；引用他人不会直接按用户本人自述处理。原文证据带由程序计算的消息顺序；主体纠正须关联同一条线索，且新证据在原线索之后。失败评估不得应用任何纠正。允许从不明确状态升级为明确当前支持需求。该澄清规则仍待专业审核。

评估失败时使用服务受限文案，已有即时支持需求时保持即时支持文案。即时支持绕过普通知识检索和自由生成，不会显示“已转接”“已通知”或虚构号码。

输出检查结合原始对话、状态和知识卡；本地规则只能发现部分明显问题，模型检查同样会出错。任何检查不通过、格式无效或预算耗尽都不展示待检查草稿。

policies 下全部策略与备用文案的专业审核状态为 pending。没有已核实电话号码，也没有人工接入服务。
