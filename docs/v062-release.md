# v0.6.2 聊天界面精简

用户将后续工作重心转到从对话探索性格，本轮先简化聊天时的界面。小测试题本、计分及17个可作答版本保持现状。

- 聊天只显示一层会话工具栏。新建、导出、连接设置和清空收进“更多”，功能首页保留直接入口。
- 使用统一白色聊天背景，助手回复移除卡片边框；用户消息保留浅色区分。空聊天改成一句开场和三个紧凑的预填按钮。
- 正常回复不重复显示“回复已生成”及动作标签；备用、错误和当前支持指引继续显示相应状态。反馈按钮仍保留，不会额外调用模型。
- 性格探索改为一行状态、报告入口及“探索详情”。详细主题、资料量进度和设置放在详情中，平时不占用聊天正文。后台任务继续按既有同意、模式、门槛及预算运行。
- 页面不再常驻“API配置已就绪”等成功提示；未完成准备或连接失败的操作提示仍可见。

界面验收另外发现两个状态问题，已修复：

- Streamlit热更新会重建模块中的类，而会话内存仍持有旧的配置实例，原`isinstance`判断将它误判为未配置。现在仅接受同模块、同限定名的旧配置dataclass，经当前构造器重新验证后在原会话归一化。拒绝字典、其他对象、非法值及第三方地址；不回退本机配置，也不将身份迁移当作凭据更换而撤回原有同意。
- 自动观察启动后台任务后，触发一次整页刷新，使聊天状态行显示正在整理；已有待处理任务不重复启动或刷新，完成轮询沿用原行为。分析门槛和请求预算不变。

验证记录：

- 完整`python -m pytest -q`：548 passed in94.61s；`python -m scripts.check_data`：`valid=true`。
- 热更新迁移三条回归先失败后通过，连接范围最终19项通过；后台状态回归先失败后通过，对应导航与观察范围11项通过。独立只读审查未发现可操作问题。
- 实际IAB本机页面核对有消息和空聊天两种布局，单层工具栏、“更多”菜单、探索详情和报告入口可用。既有聊天记录与自动观察保留，旧会话配置恢复就绪且输入框可用，没有重新填写密钥或刷新浏览器。打开报告显示额外请求0/6，未点击整理或发送消息。
- 本轮没有模型API请求；只验证界面、状态及兼容处理。截图仅保存在本机，不发布聊天内容、凭据或运行数据。

本轮为界面与状态兼容调整，不调整性格推断提示词、分析门槛或结论规则，不宣称提高心理测量准确性。
