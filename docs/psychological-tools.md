## 依恋参考的探索性边界

原创12题每次先选一段重要关系，同次所有题目都指向同一对象，按照最近一个月的通常感受作答。切换关系后，新答案与旧结果区分；旧结果保留当时的关系标签，不自动移到新关系。原创12题仅保存最近一次结果。ECR-R36询问平时亲密伴侣关系的一般感受；ECR-RS9按版本与关系对象分别保存草稿、答案和结果，可回看该对象的上次结果。

依恋练习仅采用明示的中点启发式：任一维度均分落在 2.5—3.5（含边界）时显示“混合或暂不清晰”；其他情况按两维度低于 2.5 或高于 3.5 的组合描述较接近安全、较多关系焦虑、较多亲近回避或二者并存的本次应答倾向。规则与边界未经验证，不是有效测量阈值、心理诊断或稳定依恋类型。应同时查看两维原始得分及关系处境。

## 数据流、调用与记录

17份问卷、八题偏好自述和自我确认均本机处理，不调用 API，也不自动加入聊天模型上下文。对话性格分析单独要求研究范围确认、DeepSeek配置就绪、API数据流向及费用确认、至少两段用户消息，以及明确同意分析当前对话。手动整理须主动点击，自动整理须另行设置并确认启用；每次分析最多两次请求，共享40秒截止时间，手动、自动、修复及旧MBTI入口共享每会话6次额外请求额度。发送资料仅包含已授权范围内当前对话的用户消息ID与文字；自动整理门槛及限制见README。

模型引用必须与指定用户消息的连续非空原文完全一致，不能引用助手文字。程序排除四字母自报标签及其片段作为偏好依据；每个单向维度至少需要两段不同用户消息，反例保留为矛盾，证据不足保留未知。这是工程门槛，不能证明语义推断正确、跨情境稳定或达到测量信度。旧观察会在用户文字更新后提示待更新；失败结果不覆盖已有观察。当前需优先即时支持时暂停探索界面。

`ExplorationState` 归属于各 `Conversation`，数据只保存在当前浏览器会话对应的服务端内存中。新对话隔离；清空或移除对话同时清除探索数据；也可单独清除探索记录及其控件。性格报告和问卷报告需要分别主动下载，不加入原有聊天导出。性格报告包含偏好、自述与原话依据；问卷报告包含得分、关系标签（如适用）、来源和适用说明。两者均不包含 API 配置或内部指纹。关闭或刷新后内存数据可能丢失；本地清除不等于删除已发往供应商的数据。
