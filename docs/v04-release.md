# v0.4 阶段性发布记录

日期：2026-10-29。阶段性源码提交，成年人虚构案例、本地非商业研究原型；不启用真实用户试用。

新增大五TIPI10/Mini-IPIP20/IPIP50与SWLS3/5版本目录，版本身份、答案、计分和导出分别保存。不同量表分数不合并，不把大五转换成MBTI。IPIP100、BFI系列及ECR候选版本尚未启用。

新增按主题单独授权的对话观察与手动/自动调度。默认关闭；需先确认研究范围、DeepSeek数据流向和费用。首次自动门槛为20条候选用户消息及1,000非空白字符，后续新增10条复查，每会话最多3次自动整理；手动、自动、结构修复与旧MBTI入口共享6次额外请求。每次最多2请求、40秒。这些是保守工程参数，不是科学有效性阈值。

后台观察使用不可变快照，返回时核对会话、授权、代际和修订；撤回、删除及纠正不会被迟到结果恢复。结果保留逐条原话、反例、状态与未知，校验字面来源、三消息/三事件/两情境门槛及授权域。匿名关系是可选项；依恋明确方向需由用户标注具体消息所属对象，两个朋友不合并。不输出类型诊断、概率、常模或问卷替代分数。语义误读仍可能发生。

记录只保留当前浏览器会话对应服务端内存，不默认持久化、不用于训练。刷新可能丢失，需用户主动导出。删除本地数据不等于删除供应商已收到的数据。离线演示不伪造人格观察。

最终代码完整测试由主任务执行：`python -m pytest -q`，**296 passed in 25.41s**。最终独立评审的三项问题均先复现失败再修复：非依恋观察携带关系ID而绕过删除、超限消息重绑定历史关系、清探索记录重置自动次数。任务审查也修复了嵌套快照可变性、未授权纠正元数据和撤权后修复请求。测试通过证明受测工程行为，不证明心理测量准确。

真实DeepSeek运行时仅进行1次请求，输入为3个事件的合成案例；返回status=ok，EI为I，其余多数未知。该例只核对链路及输出，不是准确率验证，也不宣称效果提升。运行报告和本地配置不在公开源码清单中。
