# v0.7 有目的的对话采集与分层观察

2026-10-31。修复“开了性格分析，聊天仍泛泛倾听；报告大多只写信息不足”的实际链路问题。小测试继续保持17版本。

## 行为变化

- 已启用的主题、匿名关系与可核验缺口传入原有聊天流程。assessment在同一次请求内整理本轮回答到哪一层，response/check共享一个取证计划；没有额外分类请求。
- 请求关系话题但尚无对象时，先确认范围而不绕回通用性格；聊天与探索详情提供匿名对象快捷入口，新建后可直接返回聊天，旧消息不自动绑定。暂停请求即使在回复检查失败时也会保留；停止人格访谈不会阻断与当前支持直接相关的必要澄清。
- 一次一个开放问题，先了解行动与主要考虑，再对照其他场合和反例。已明确的行为不再被当成单纯事件背景；跳过、暂停、仅倾诉、当前支持需求优先。只有回复通过检查才推进访谈阶段。
- 已核验旧例子可在后续新增消息时继续用于选问题，但必须保持来源全文指纹、同意代次、对象范围一致；它们不能证明新增消息的内容。清空对话重置访谈进度。
- 独立审查补齐三条边界：暂停人格问题不误禁普通支持澄清；修改关系或观察范围不会自行恢复已暂停的问题；后台运行时只给新增消息绑定关系，不再误作废旧快照报告，原消息改绑仍会作废。各项均有先失败后通过的正反回归，复核未发现新增明确问题。
- 分开显示初步线索、多次经历支持、情境差异、当次感受及范围待确认。原有三消息、三事件、两情境的单向支持要求保留；一两条有价值的材料不再被压成同一条unknown。每维有具体含义、缺口、原话、待核对替代解释及下一问，界面和导出一致。
- 同一消息中的不同引用可以保留；同一引用不能自作反例。支持与反例重复或重叠时降为待核对，不能靠删除反例升为单向支持。模型自行输出的证据等级会被剥除后由程序重算。
- 界面只允许虚构研究案例，分析器却排除角色材料的旧冲突已修正：可信synthetic_case模式允许同一案例叙述者case_narrator；他人、引述和未发生的假设仍不能变成本人习惯。模拟结果不作为真实用户画像。

## 调度、模型与边界

自动首次6条有效表达且240个非空白字符，随后每新增6条复查。候选至少5个字母或数字，去掉重复和简短应答；手动仍为2条。每对话最多3次自动整理、全部探索共享6次额外请求。

普通聊天仍最多4请求、20秒/请求、45秒共享。后台观察独立purpose使用6000 tokens输出上限，对支持的DeepSeek模型开启thinking；实测高推理预算出现超时或未能返回合规最终内容，最终采用low effort，为证据JSON保留时间和空间。后台最多2请求、45秒/请求、90秒共享；旧MBTI独立入口仍40秒。模型ID和官方主机限制不变，不保存、展示或回传reasoning_content。参数依据[DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)及[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。

仍保留18,000字符聊天与16,000字符分析上限，不静默截断。上下文超限、调用失败或引用失败会显示相应状态，不再统称性格信息不足。未分析的维度不会被猜齐；不存在人格概率、官方量表分数或临床效用结论。

- 有意义的回归先失败后通过：范围接线、动作/动机推进、拒绝及当前需求优先、旧快照来源复用、清空复位、初步等级、重叠反例、可信案例主体、独立关系、预算和模型请求参数。17份问卷原有回归保留。

- 最终受控推理配置以2请求复验完整模式与独立反例：两次HTTP200、finish_reason=stop且有最终内容；完整案例产生EI、尽责性、JP的有支持趋势，关系案例保留两侧原话并呈现mixed/conflicting。早期单条案例另成功显示limited与state，未变成支持趋势。
- 完整记录的调优运行共27次模型请求；受限环境连接失败另有诊断记录。只读联网主机检查不调用模型。没有用真实网页对话作评测，没有记录或发布密钥、模型思维过程。
- 这些是开发方固定案例的提示词调优回归，包含同一组材料的复验，不是独立人格准确率或泛化能力研究。实际报告与截图只在本机，源码仓库只包含代码、固定虚构输入及说明。
