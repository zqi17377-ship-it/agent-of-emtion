# v0.5 分步使用流程

本次将“知心”的主要功能改为按顺序进入的独立页面，保留现有本机计分、会话记录和明确授权机制。此版本仍仅用于成年人虚构案例的本地非商业研究，专业审核未完成，真实用户试用尚未启用。

## 首页与聊天准备

首次首页只提供三个主要入口：“开始对话”“做心理小测试”“从对话探索自己”，不同时展开问卷与连接设置。顶栏“功能首页”可返回入口。

开始对话依次经过三步：选择连接方式、确认研究使用范围、准备开始。默认离线演示使用固定示例回复。选择 DeepSeek API 时，最后一步说明模型连接及数据发送、费用确认；本机配置就绪并完成确认后才能进入可发送消息的聊天页。研究范围与API同意使用独立会话状态保存，换页后仍有效；仅完成准备不会发送聊天请求。

聊天页保留消息、输入框、场景卡片和对话观察入口。场景卡片只填入输入框，反馈不请求模型。切换连接方式时，已有消息的旧对话保留在侧栏，另开对话。会话管理与主动导出继续保留。

## 心理小测试

先选择功能；大五可选10、20或50题版本，生活满意度可选3或5题。阅读当前工具的说明、研究范围与来源后开始，依恋原创练习另有独立的关系选择页。

题目每页只显示一题，页面显示步骤进度、已答和剩余题数；未答不能进入下一题。上一题、返回功能选择以及切出后重新进入均保留草稿。草稿按当前对话、完整版本和关系隔离，不把不同版本或不同对象的答案混用。

全部题目完成后进入只读核对页，确认提交才保存答案与计分结果，然后进入独立结果页。结果页可下载记录或返回修改；修改中的草稿不会覆盖上次结果，重新提交后才更新。已有结果也可从说明页单独查看。问卷计分完全在本机进行，不调用API，不自动把答案交给模型。来源、翻译、许可和计分说明放在说明页的可展开详情中，产品页面不展示内部版本标识。

## 对话探索

设置按五步展开：了解范围、连接与API费用、选择主题、选择整理方式、同意并确认启用。选择手动或自动只是草稿，最终单独同意并点击确认后才启用。默认关闭，未同意不发送观察请求。

启用后单独显示状态；修改设置、管理关系对象、逐条消息标注、观察报告各有独立入口与页面，暂停并撤回同意的入口保持可见。缺少关系对象或消息时给出下一步引导。正常聊天回复先完成，后台整理不阻断聊天。既有请求预算、触发门槛、原文与反例展示、未知处理以及修正或删除观察机制保持有效。

## 软件与界面验证

2026-10-30 最终完整回归：`python -m pytest -q`，313 passed in 39.03s；数据检查返回 `valid: true`。新增用例覆盖首次首页、顺序聊天准备、单题展示与草稿、最终确认保存、观察设置未确认不启用，以及关系对象和消息标注的独立页面。

实际本机浏览器走通 SWLS 三题、返回恢复答案、核对后独立显示12/21结果；核对 IPIP50 每页仅显示当前一题和剩余题数；走通聊天三步及观察五步设置。观察设置完成时额外请求为0。本轮未调用模型API，也未新增心理测量或临床有效性结论。本机服务已加载此版本。

## MBTI 风格探索

人格功能页分别进入“从对话观察偏好”“八题偏好问答”“我的自我确认”和“查看已保存记录”，不在同页展开全部内容。

八题原创偏好问答每页一题，可以选择不确定；自我确认按四个维度逐项填写，可以暂不确认。两者在本机处理，返回保留草稿，核对并保存后才更新记录。对话观察另行经过范围、分析同意和模型连接确认，只有主动开始分析才请求模型。已有记录与填写页面分开，失败分析不覆盖上次观察。

## 保留的研究与数据边界

这些功能不构成心理诊断或官方 MBTI 施测。依恋、应对信心和偏好问答包含未经验证的原创练习；研究自译工具未经中文信效度验证，SWLS 仅限非商业研究使用。具体题目来源、许可及计分限制见[心理探索工具说明](psychological-tools.md)。

记录仍在当前浏览器会话对应的服务端内存中，刷新或关闭后可能丢失，需要保留时主动导出。清空本轮同时清除该对话探索记录，其他对话继续保留。页面和报告不显示密钥；本机配置就绪不等于已验证实际API调用。离线演示不生成模拟性格结论，模型产生的解释仍需核对，专业审核与真实用户流程仍待完成。
