# 中文心理支持 Agent · 研究原型

v0.5.1 统一使用 DeepSeek API，移除产品中的离线演示和模式选择。首页提供“开始对话”“做心理小测试”“从对话探索自己”三个入口；聊天先确认研究范围，再检查连接与数据发送、费用确认。问卷每页只答一题，显示进度、保留返回草稿，核对后才提交计分；对话探索按五步单独确认，MBTI 风格探索按子功能分别进入。保留大五10/20/50题和生活满意度SWLS3/5题版本、多会话、聊天导出、单条反馈与本机配置热更新。自动探索默认关闭，所有功能仍仅用于成年人虚构案例的本地非商业研究，真实用户试用尚未启用。

已实现本地聊天页面、DeepSeek 接口适配、结构化信息整理、五种回应动作、知识卡检索、输出检查与合成案例评测。对话与模型分析使用真实 API；配置缺失时提示修复，调用失败时显示相应状态。仅输入成年人虚构案例。真实用户试用尚未启用，专业审核未完成。

## 立即运行

在项目文件夹双击 **start_demo.bat**。或在 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的本机网址，默认是 http://127.0.0.1:8501 。首页按本次想做的事选择入口：

- **开始对话**：先确认研究使用范围，再检查 DeepSeek 连接配置并确认数据发送与调用费用，完成后进入聊天。准备页面本身不发送对话请求；发送消息后使用真实 API。
- **做心理小测试**：先选择功能；大五和生活满意度再选择版本或题数。阅读说明并确认研究范围，依恋练习另选同一段关系，然后逐题填写。页面显示已答及剩余题数；可返回修改或切出功能，重新进入时继续草稿。全部答完进入只读核对页，确认提交后才保存计分结果。
- **从对话探索自己**：依次了解范围、确认连接与API费用、选择主题、选择手动或自动整理方式，最后单独同意并确认启用。仅浏览设置或选择自动方式不会启用观察。

顶栏“功能首页”可以返回入口。已有对话保留在侧栏，新对话有各自独立的消息与探索记录。

点击场景卡片只会填入输入框，不会自动发送或计费。“有帮助/需改进”反馈只保存在当前浏览器会话，也不会再次调用模型。导出按钮只下载当前对话的可见文本；不包含内部评估、证据或密钥。

“清空本轮”清除当前对话、反馈及探索记录；其他对话继续保留。最多保留 10 个对话，可在侧栏“会话管理”中主动移除。关闭或刷新页面后，这些内存记录可能丢失，需要保留时请主动导出。

命令行版本：

```powershell
.\.venv\Scripts\python.exe -m support_agent.cli
```

命令行也默认使用 DeepSeek API，输入消息会产生 API 用量。输入 `/clear` 清除会话，`/quit` 退出。

## 心理探索

从首页“做心理小测试”选择工具。大五可选TIPI10、Mini-IPIP20、IPIP50，生活满意度可选SWLS3/5；不同工具和版本分别记录，不按题数混合分数。每页只显示当前一题，50题版本也不展开整份表单。问卷在本机计分，不调用API，也不自动把答案发给模型；缺题不能继续，核对后确认提交才保存。修改草稿不会覆盖上次结果；上次结果可单独查看。依恋原创练习仍围绕同一段关系作答，不同关系的草稿分别保留。

MBTI 风格探索分别提供“从对话观察偏好”“八题偏好问答”“我的自我确认”和“查看已保存记录”。八题问答每页一题，可选不确定；自我确认按四个维度逐项填写，两者核对后才保存。本机问答无需连接模型；对话观察另行确认研究范围、分析同意及API连接。

从首页“从对话探索自己”或聊天页“设置对话探索”进入五步设置，先完成成年人虚构研究范围、API数据流向与费用确认，再选择允许主题和整理方式，最后单独同意分析当前对话并确认启用。未同意时不发送观察请求，默认关闭。正常聊天回复先完成，后台观察不会阻断聊天。

自动整理首次需要20条候选用户消息及至少1,000个非空白字符；之后每新增10条复查，每段对话最多3次自动整理。手动、自动、结构修复和旧MBTI入口共享每会话6次额外请求额度，每次观察最多2请求、40秒。重复和空白不用于凑数；这些是工程门槛，不是测量有效性的保证。

关系匿名对象为可选项；要观察依恋方向，需由用户把具体消息标注到同一匿名关系对象，不同朋友不能共用证据。观察逐条显示原话、反例和未知，可以修正为当前状态、不认同或删除。明确方向初步要求3条不同消息、3个不同事件及2类情境，字面引用校验不能证明心理解释正确。

记录按对话保存在当前浏览器会话对应的服务端内存中。对话更新会标记旧观察；失败分析保留上次观察并提示。可以单独清除本对话的探索记录，不清除聊天。性格与问卷各有主动下载按钮，原聊天导出仍只包含聊天可见文本；探索报告不包含 API 配置或内部指纹。

这些工具只供成年人虚构案例的本地非商业研究。MBTI 风格并非官方施测；依恋和应对信心题目为未经验证的原创练习。Mini-IPIP、TIPI、RSES、SWLS 使用项目研究自译，未经中文信效度验证。SWLS 仅限非商业研究使用。具体题数、来源、许可、计分与限制见 [心理探索工具说明](docs/psychological-tools.md)。

## 配置 DeepSeek

已准备 `.env.example`；如果没有 `.env`，复制一份并改名为 `.env`。用本机编辑器填写：

```dotenv
LLM_API_KEY=在本机填写你的密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
```

不要把密钥发到聊天、报告或 Git。`.gitignore` 已排除 `.env`。默认模型名称依照 2026-10-29 核查的 [DeepSeek 官方入门文档](https://api-docs.deepseek.com/)；可以按自己账号支持的模型改名。没有真实密钥时无法完成实际 API 验证。

在聊天准备页确认只输入虚构案例及数据流向、费用后，才可发送消息。连接统一使用 DeepSeek API。本机 .env 修改会在下一次读取时刷新，不需要重启程序；显式进程环境变量优先于文件配置。页面仅显示配置是否就绪，不显示密钥；配置就绪不等于已经验证接口可用。命令行启动方式：

```powershell
.\.venv\Scripts\python.exe -m support_agent.cli
```

模型只发送至官方 DeepSeek 主机，任意第三方地址会被拒绝。聊天每轮最多 4 次请求，单次本地等待最多 20 秒，共享 45 秒截止时间；对话探索每次最多 2 次请求、40 秒共享截止时间，手动、自动、结构修复与旧 MBTI 入口共享每会话 6 次额外请求额度。超时后供应商仍可能处理已收到的请求，不能保证远程取消或免计费。没有无限重试。

接口采用非流式输出，JSON 模式按[官方说明](https://api-docs.deepseek.com/guides/json_mode/)请求，并在本机重新校验。结构化输出不保证内容正确；证据引用错误、检查失败或预算不足时使用备用回复。

## 环境

本机已用 Python 3.13.5 验证。计划原定 3.12，版本调整记录在 docs/execution-progress.md。本机虚拟环境复用已安装依赖，以避开执行环境临时目录写入限制；尚未验证一台全新机器从零安装。

另一台电脑正常创建环境时：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

requirements.txt 为本次验证环境的依赖快照；requirements.in 是直接依赖范围。

## 项目资料的实际状态

- 40 张知识卡为本项目新编、AI 辅助的日常支持草稿，未复制受限数据集；全部 `review_status=pending`，不是经过临床审核的医学知识库。
- 80 个开发案例、40 个保留案例全部为虚构草稿。保留集与开发集无家族 ID 交叉，但由同一开发方编写、可见，不是独立临床金标准。
- 安全相关多轮场景重复 3 次仅检查运行稳定性。历史离线报告不计算模型识别率、临床效果或实际 API 花费；单例 API 连通验证也不能证明心理判断准确性。
- eligible_pilot 模式在运行入口中禁用。专业内容、求助资源、真实用户数据流与试用流程均需进一步审核。

## 数据与安全行为

会话仅保存在当前进程的会话内存中，普通日志不记录原文、密钥或完整模型回复。清除会话会同时清除消息、历史判断和证据；这不等于删除供应商端数据。报告仅允许虚构案例。

每轮提取信息时允许未知和矛盾，使用原文证据；持续时间和生活影响必须能引用用户原文。程序不输出确定诊断、医学概率或个体化处方。模型可能漏掉、误解安全线索，备用文案也尚待专业审核。当前工具没有实际转接医生、通知家属或呼叫救援的能力。
