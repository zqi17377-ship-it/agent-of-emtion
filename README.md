# 中文心理支持 Agent · 研究原型

v0.6.2 将本轮重点转向聊天与从对话探索性格，精简聊天正文：单层工具栏，“更多”收纳新建、导出、连接和清空；正常回复不再重复显示动作成功提示，异常与紧急提示保留。观察缩为一行状态及报告入口，主题、资料门槛、进度和设置收进“探索详情”。空聊天显示简短开场和三个紧凑预填按钮。

小测试沿用v0.6.1的17个可作答版本，包括ERQ-30情绪调节与AAQ-II心理不灵活/经验性回避两份英文原版，本轮没有新增或更改问卷。小测试目录仍有12个主入口：10类问卷、MBTI风格和对话观察；BEQ16、FFMQ39仅列待接入资料，不计入可作答数量。问卷保留逐题填写、核对、图表、对应解读和导出。每位网页使用者填写自己的DeepSeek配置，仅当前会话内存持有。自动探索默认关闭，所有功能仍仅用于成年人虚构案例的本地非商业研究，真实用户试用尚未启用。

已实现本地聊天页面、DeepSeek 接口适配、结构化信息整理、五种回应动作、知识卡检索、输出检查与合成案例评测。对话与模型分析使用真实 API；配置缺失时提示修复，调用失败时显示相应状态。仅输入成年人虚构案例。真实用户试用尚未启用，专业审核未完成。

## 立即运行

在项目文件夹双击 **start_demo.bat**。或在 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的本机网址，默认是 http://127.0.0.1:8501 。首页按本次想做的事选择入口：

- **开始对话**：先确认研究使用范围，再检查 DeepSeek 连接配置并确认数据发送与调用费用。未设置时，从侧栏或连接步骤进入“API设置”，填写自己的密钥与模型，保存后返回继续。准备与保存设置不发送对话请求；发送消息后使用真实 API。
- **做心理小测试**：先选择功能；大五和生活满意度再选择版本或题数。阅读说明并确认研究范围，依恋练习另选同一段关系，然后逐题填写。当前题目的单选项直接展开，初次进入未预选答案。页面显示已答及剩余题数；可返回修改或切出功能，重新进入时继续草稿。全部答完进入只读核对页，确认提交后才保存计分结果，查看图表与文字解读。
- **从对话探索自己**：依次了解范围、确认连接与API费用、选择主题、选择手动或自动整理方式，最后单独同意并确认启用，随后直接进入聊天输入框。启用后从聊天页“探索详情”中的“设置对话探索”重新打开设置和关系标注，状态行“打开观察报告”可直接查看报告。仅浏览设置或选择自动方式不会启用观察。

顶栏“功能首页”可以返回入口。聊天顶栏的“更多”提供新对话、导出、连接设置及有聊天记录时的清空操作。已有对话保留在侧栏，新对话有各自独立的消息与探索记录。

在侧栏展开“会话管理”，点击“重命名当前对话”，填写1—40个字符的名称，选择“保存名称”或“取消命名”。保存的自定义名称不会被后续消息自动覆盖；“清空本轮”会将当前对话名称重置为“新的对话”。

点击空聊天页的预填按钮只会填入输入框，不会自动发送或计费。“有帮助/需改进”反馈只保存在当前浏览器会话，也不会再次调用模型。“更多”中的导出按钮只下载当前对话的可见文本；不包含内部评估、证据或密钥。

“清空本轮”清除当前对话、反馈及探索记录；其他对话继续保留。最多保留 10 个对话，可在侧栏“会话管理”中主动移除。关闭或刷新页面后，这些内存记录可能丢失，需要保留时请主动导出。

命令行版本：

```powershell
.\.venv\Scripts\python.exe -m support_agent.cli
```

命令行也默认使用 DeepSeek API，使用下文的本机 `.env` 配置；网页保存的密钥不写入命令行配置。输入消息会产生 API 用量。输入 `/clear` 清除会话，`/quit` 退出。

## 心理探索

从首页“做心理小测试”选择工具。大五可选TIPI10、Mini-IPIP20、IPIP50/100，生活满意度可选SWLS3/5，自我关怀可选SCS26/SCS-SF12；依恋入口保留原创12题，并增加ECR-R36和每关系ECR-RS9。另有RSES10自尊、原创6题应对信心、MAAS15日常正念觉察、DOSPERT30分领域风险行为意向，以及ERQ-30与AAQ-II英文原版。不同工具和版本分别记录，不按题数混合分数。每页只显示当前一题及全部单选项，默认未答，100题版也不展开整份表单。问卷本机计分，不调用API，不自动把答案发给模型；缺题不能继续，核对后确认提交才保存。

ERQ-30保留英文指导语、30道原题及原作答锚点，分别加总十种情绪调节策略，每种3—21分，不合成总分。AAQ-II保留英文7题，全部正向加总7—49分；高分表示更多心理不灵活或经验性回避。两项只有界面和结果说明使用中文，不提供项目自译或宣称已验证中文版。待接入资料折叠区中的BEQ16仍缺少覆盖当前个人研究用途的明确许可，FFMQ39仍缺明确嵌入授权，因此均未内置题目、不可作答。

SCS26按三个负向面向反向计分后，先算六个面向均分，再等权平均得到整体自我关怀；展示六维量程图及单独总体。SCS12只展示总体，不输出六维画像。MAAS15使用原1“几乎总是”至6“几乎从不”锚点，直接均分；高分表示较多正念注意觉察。DOSPERT30只测行为意向，按五领域分别加总6—42，不给跨领域总分、道德判断或风险行为建议。

ECR-R36询问平时亲密伴侣关系的一般感受。ECR-RS9先选母亲、父亲、伴侣或最亲近朋友中的一个对象；不同对象的草稿、已完成结果和导出分别保留，可选择“查看这段关系的上次结果”。两者只展示焦虑/回避两维1—7均分，不套用原创12题的类型参考。原创12题仍按原有方式保存最近一次结果。

大五10/20/50/100题的结果以五维雷达图展示，各轴依原工具保留名称和得分方向：Mini-IPIP的负性情绪倾向与其他版本的情绪稳定性方向相反，不为了图形一致而反转分数。其他测试使用原始量程横图，保留各维度方向。图形位置不是概率或人群百分位，雷达面积不是人格总分，不直接比较不同工具的图形大小。

结果页按每个维度解释本次自报的得分方向，附具体反思问题；解读由本机规则生成，下载记录包含相同的文字解读，不自动发送给API。量程较低、中间、较高只按该量程的三段辅助描述，没有常模或诊断含义。生活满意度、自尊和应对信心分别描述相应主题，不用于确定人格类型。

MBTI 风格探索分别提供“从对话观察偏好”“八题偏好问答”“我的自我确认”和“查看已保存记录”。八题问答每页一题，可选不确定；自我确认按四个维度逐项填写，两者核对后才保存。保存八题问答后，结果页增加“本次偏好解读”和反思问题；两题不同方向时保留两种线索，不确定或缺项时暂不归类，不据此确定稳定人格类型。导出记录保留同一份偏好解读。本机问答无需连接模型；对话观察另行确认研究范围、分析同意及API连接。

从首页“从对话探索自己”或聊天页“设置对话探索”进入五步设置；启用后设置入口收在“探索详情”中。先完成成年人虚构研究范围、API数据流向与费用确认，再选择允许主题和整理方式，最后单独同意分析当前对话并确认启用。未同意时不发送观察请求，默认关闭。正常聊天回复先完成，后台观察不会阻断聊天。

主题与整理方式在设置步骤直接展示并附简短说明，至少选一个主题才能继续。确认“启用并开始对话”后直接进入当前聊天。聊天观察状态行显示当前资料积累或整理状态，“打开观察报告”可查看已有结果或进入手动整理；主题、资料门槛、进度和设置位于“探索详情”。导航本身不发送请求。进度不代表性格分数或判断准确度，过短、重复及助手消息不用于累计。

自动整理首次需要20条候选用户消息及至少1,000个非空白字符；之后每新增10条复查，每段对话最多3次自动整理。手动、自动、结构修复和旧MBTI入口共享每会话6次额外请求额度，每次观察最多2请求、40秒。重复和空白不用于凑数；这些是工程门槛，不是测量有效性的保证。

关系匿名对象为可选项；要观察依恋方向，需由用户把具体消息标注到同一匿名关系对象，不同朋友不能共用证据。观察逐条显示原话、反例和未知，可以修正为当前状态、不认同或删除。明确方向初步要求3条不同消息、3个不同事件及2类情境，字面引用校验不能证明心理解释正确。

记录按对话保存在当前浏览器会话对应的服务端内存中。对话更新会标记旧观察；失败分析保留上次观察并提示。可以单独清除本对话的探索记录，不清除聊天。性格与问卷各有主动下载按钮，原聊天导出仍只包含聊天可见文本；探索报告不包含 API 配置或内部指纹。

这些工具只供成年人虚构案例的本地非商业研究。MBTI 风格并非官方施测；原创依恋12题和应对信心6题为未经验证的原创练习。已接入的中文量表使用项目研究自译，未经中文信效度验证；ERQ-30和AAQ-II使用英文原版，原研究证据不等于本应用已完成独立或临床验证。具体题数、来源、许可、计分与限制见 [心理探索工具说明](docs/psychological-tools.md)。

## 配置 DeepSeek

网页使用者从侧栏“API设置”进入独立页面：

1. 在遮罩输入框填写自己的 DeepSeek API Key，核对模型名称，点击保存。默认模型为 `deepseek-flash`，可按自己账号支持的模型修改；地址固定为官方 DeepSeek，不接受任意第三方URL。
2. 如需检查可用性，主动点击测试连接。测试只用已保存配置发送一次简短请求，不包含聊天记录，可能产生API费用；保存本身不调用API。
3. 返回原功能继续使用。需要移除凭据时清除本次配置，清除后网页不能发送模型请求，也不会借用部署者的密钥。

每个新网页会话从未配置开始。密钥由当前会话对应的服务端处理并暂存在内存，不写入文件、进程环境、日志或导出，也不向其他访问者共享。保存后不回显密钥；刷新或关闭后配置可能丢失。留空密钥可保留本次已保存的密钥，仅修改模型；首次保存必须填写密钥。

保存更改或清除API配置会暂停当前网页会话中的对话观察并撤回相应启用同意；消息和已保存的问卷、性格结果保留。需要继续观察时重新设置并同意启用。已经发出的远程请求无法撤销。

命令行与独立脚本仍使用本机配置。已准备 `.env.example`；如果没有 `.env`，复制一份并改名为 `.env`，用本机编辑器填写：

```dotenv
LLM_API_KEY=在本机填写你的密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
```

不要把密钥发到聊天、报告或 Git。`.gitignore` 已排除 `.env`。供应商接口说明见 [DeepSeek 官方入门文档](https://api-docs.deepseek.com/)。没有真实密钥时无法完成实际 API 验证。

在聊天准备页确认只输入虚构案例及数据流向、费用后，才可发送消息。网页仅使用本次网页会话保存的配置；修改本机 `.env` 不会更改网页使用者的配置。命令行和独立脚本下一次读取时会刷新 `.env`，显式进程环境变量优先。配置就绪不等于已经验证接口可用。命令行启动方式：

```powershell
.\.venv\Scripts\python.exe -m support_agent.cli
```

模型只发送至官方 DeepSeek 主机，任意第三方地址会被拒绝。聊天每轮最多 4 次请求，单次本地等待最多 20 秒，共享 45 秒截止时间；对话探索每次最多 2 次请求、40 秒共享截止时间，手动、自动、结构修复与旧 MBTI 入口共享每会话 6 次额外请求额度。超时后供应商仍可能处理已收到的请求，不能保证远程取消或免计费。没有无限重试。

接口采用非流式输出，JSON 模式按[官方说明](https://api-docs.deepseek.com/guides/json_mode/)请求，并在本机重新校验。结构化输出不保证内容正确；证据引用错误、检查失败或预算不足时使用备用回复。

## 项目资料的实际状态

- 40 张知识卡为本项目新编、AI 辅助的日常支持草稿，未复制受限数据集；全部 `review_status=pending`，不是经过临床审核的医学知识库。
- 80 个开发案例、40 个保留案例全部为虚构草稿。保留集与开发集无家族 ID 交叉，但由同一开发方编写、可见，不是独立临床金标准。
- 安全相关多轮场景重复 3 次仅检查运行稳定性。历史离线报告不计算模型识别率、临床效果或实际 API 花费；单例 API 连通验证也不能证明心理判断准确性。
- eligible_pilot 模式在运行入口中禁用。专业内容、求助资源、真实用户数据流与试用流程均需进一步审核。

## 数据与安全行为

会话仅保存在当前进程的会话内存中，普通日志不记录原文、密钥或完整模型回复。清除会话会同时清除消息、历史判断和证据；这不等于删除供应商端数据。报告仅允许虚构案例。

每轮提取信息时允许未知和矛盾，使用原文证据；持续时间和生活影响必须能引用用户原文。程序不输出确定诊断、医学概率或个体化处方。模型可能漏掉、误解安全线索，备用文案也尚待专业审核。当前工具没有实际转接医生、通知家属或呼叫救援的能力。
